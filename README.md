## **Proyecto de un sistema en el cual se aplicaron patrónes de diseño**
### **Descripción del proyecto
Consiste en un sistema de gestión de ropa realizado como proyecto final del curso analisis de sistema ll, en el cual se aplican los patrónes de diseño para poder tomar un optimo desempeño y se trataron de aplicar buenas practicas, los cuales fueron:
1. Patrón Creacional
   - Factorý
   - Builder
   - Prototype
   - Singleton
2. Patrón Estructural
   - Adapter
   - Aggregate
   - Bridge
   - Composite
3. Patrón Conductual
   - Command
   - Listener
   - Interpreter
   - Iterator

### **Funcionalidad**
- Gestión de materia prima y verificación de registros
- Creación de producciones y visualizción de los etados
- Gestion de productos terminados
- Creación de conjuntos dependiendo la temporada
