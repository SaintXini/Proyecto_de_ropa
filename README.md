## 📋 Descripción / Description

**ES:** Sistema de gestión de ropa que permite administrar materia prima, controlar producciones, gestionar productos terminados y crear conjuntos según la temporada. Desarrollado aplicando patrones de diseño creacionales, estructurales y conductuales para garantizar un código limpio, escalable y mantenible.

**EN:** Clothing management system that allows managing raw materials, controlling productions, managing finished products, and creating outfits by season. Developed applying creational, structural, and behavioral design patterns to ensure clean, scalable, and maintainable code.

---

## ✨ Funcionalidades / Features

- Gestión de materia prima y verificación de registros / Raw material management and record verification
- Creación de producciones y visualización de estados / Production creation and status visualization
- Gestión de productos terminados / Finished product management
- Creación de conjuntos dependiendo la temporada / Seasonal outfit creation
